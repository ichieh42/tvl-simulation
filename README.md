# TvL 模型模拟 — 天才 vs 运气 (Talent vs Luck)

> 基于意大利卡塔尼亚大学 Pluchino, Biondo & Rapisarda (2018) 的研究，用计算机模拟揭示运气在个人成功中的决定性角色。

本研究荣获 **2022 年搞笑诺贝尔经济学奖**，通过一个极简的数学模型重现了真实社会的财富分布规律（帕累托 80/20 法则），并得出一个反直觉的结论：**运气是成功的决定性因素，才能只影响抓住机会的概率**。

## 快速开始

直接在浏览器中打开 `index.html` 即可运行，无需安装任何依赖。

```
# 克隆或下载项目后
cd tvl-simulation
# 直接用浏览器打开
open index.html      # macOS
start index.html     # Windows
xdg-open index.html  # Linux
```

或者用本地服务器运行（推荐，避免浏览器缓存问题）：

```bash
# Python
python -m http.server 8080

# Node.js (需安装 npx)
npx serve
```

然后访问 `http://localhost:8080`。

## 模型原理

### TvL 模型 (Talent vs Luck)

在 201×201 的方格棋盘上模拟 1000 个"代理人"40 年的职业生涯：

| 参数 | 值 | 说明 |
|------|-----|------|
| 棋盘大小 | 201×201 | 虚拟世界 |
| 代理人数 | 1000 | 每人初始财富 10 |
| 才能值 T | 正态分布 N(0.6, 0.1) | 综合智商、努力、教育等 |
| 事件总数 | 500 | 250 幸运(绿) + 250 不幸(红) |
| 模拟步数 | 80 | 每步半年，共 40 年 |

### 核心规则

1. **代理人不动**，事件每步随机移动 2 格
2. **幸运事件**（绿点撞到代理人）：财富有概率翻倍，概率 = 才能值 T
   - 才能越高，越能抓住幸运机会
3. **不幸事件**（红点撞到代理人）：财富一律减半
   - 灾难面前人人平等，才能无用武之地
4. 每步半年，共 80 步（40 年职业生涯）

### 关键发现

- **财富分布符合帕累托法则**：20% 的人掌握约 80% 的财富
- **最成功的人并非最有才能**：第一名才能值通常 ≈ 0.667（略高于平均值 0.6）
- **运气压倒才能**：高才能者（T > 0.7）成功率仅约 32%
- **精英主义补助效率最低**：只给表现好的人发钱，效果最差
- **全民均等补助效率最高**：给所有人小额补助，性价比最优

## 功能说明

### 1. 棋盘可视化
实时动画展示代理人和事件的移动。代理人颜色随财富变化——越富有越亮，越贫穷越暗。

### 2. 实时统计面板
- 当前步数 / 总步数
- 总财富、首富/最穷的财富与才能值
- 帕累托比（前 20% 财富占比）
- 基尼系数（不平等程度）
- Top 5 / Bottom 5 排行表（含幸运/不幸事件命中次数）

### 3. 财富分布图（对数坐标）
柱状图展示最终财富分布，验证幂律特性——在对数坐标下呈直线分布。

### 4. 才能 vs 财富散点图
横轴为才能值 T，纵轴为最终财富（对数）。直观展示才能高不等于成功。

### 5. 100 次快速运行统计
无动画纯计算 100 次完整模拟，统计：
- 每次第一名才能值的平均值（理论值 ≈ 0.667）
- 高才能者（T > 0.7）成功率（理论值 ≈ 32%）
- 平均帕累托比和基尼系数
- 第一名才能值分布直方图

### 6. 资源分配策略对比
模拟 8 种资助策略，每 5 年（10 步）向代理人发放资金，比较各策略对高才能者成功率的提升效率：

| 策略 | 预算 | 预期表现 |
|------|------|----------|
| 无补助（对照组） | 0 | 基准 ~32% |
| 全民补助 1 元 | 8,000 | **效率最高** |
| 全民补助 5 元 | 40,000 | 成功率最高 |
| 精英（前 50%）5 元 | 20,000 | 效率较低 |
| 精英（前 25%）10 元 | 20,000 | 效率较低 |
| 精英（前 10%）20 元 | 16,000 | **效率最差** |
| 随机（25%）10 元 | 20,000 | 效率中等 |
| 折衷（前 25% 得 10，其余得 5） | 70,000 | 成功率高但成本大 |

### 7. 可调参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 速度 | 1–200 步/秒 | 控制动画播放速度 |
| 人数 | 100–5000 | 代理人数量 |
| 幸运:不幸比例 | 50:50 / 80:20 / 20:80 | 模拟不同产业环境 |

- **80:20**（高增长环境）：好运远多于厄运，对高才能者有利
- **20:80**（衰退环境）：厄运远多于好运，所有人一起变差

## 技术栈

- **HTML5 Canvas**：棋盘可视化渲染
- **Chart.js 4.4**：财富分布柱状图、散点图、直方图（CDN 引入）
- **原生 JavaScript**：模拟引擎和交互逻辑，无框架依赖
- **CSS3**：暗色主题、响应式布局、CSS 变量

## 技术实现要点

### 碰撞检测
使用空间网格哈希（2D 数组 `grid[y * N + x]`）实现 O(1) 的代理人位置查找。每个事件移动后检查其位置及周围 8 格是否有代理人，总复杂度 O(500 事件 × 9 格 × 80 步)。

### 正态分布
使用 Box-Muller 变换从均匀分布生成正态分布的才能值，均值 0.6，标准差 0.1。

### 财富计算
- 幸运事件：`wealth *= 2`（以概率 T 触发）
- 不幸事件：`wealth *= 0.5`（必定触发）
- 基尼系数：排序后加权求和法计算
- 帕累托比：排序取前 20% 的财富占比
